# KakeiBOT_ex

## 日付範囲を指定した一括入力

支出チャンネルで次のメッセージを一度に送信します。

```text
!入力 260917-260921
1.2
3.1

2.19
7.98

7.45 娯楽
```

09/17に1.2と3.1、09/18に2.19と7.98、09/19に7.45（娯楽）を記録します。
最初の金額は期間初日です。金額だけを改行すると同じ日、空行を挟むと翌日です。
連続した空行は1つの日付区切りとして扱い、先頭・末尾の空行は無視します。
空行がなければ全件を期間初日に記録します。

- 日付はYYMMDD（2000〜2099年）。終了日まで全日分の入力は不要です。
- 終了日超過、逆順の期間、存在しない日付、不正な金額は全件を追加せずエラーにします。
- 金額は0以上の整数・小数です。一括入力では取消・「来月」フラグを使用しません。
- 各行は `金額 [カテゴリ] [通貨]`。カテゴリ省略時は「食費」です。
- 通貨省略時は既存のデフォルト通貨設定を使用します。例：`7.45 娯楽 USD`、`100 JPY`。
- Webhook経由でも使用できます。時刻は入力時刻です。
- 全行を検証してから「支出記録」へ一括追記します。再送は重複登録になるため、通信エラー時はシートを確認してください。

既存の単件入力、取消、通貨設定、来月計上、サブスク、予算・レポートも使用できます。

## テスト

依存関係をインストールしたPython環境でリポジトリ直下から実行します。
実際のDiscord・Google Sheetsには接続しません。

```bash
python -m unittest discover -s discord-bot/tests -v
```

## systemdサービスの更新

既存のUbuntu VMでは次の配置・サービス名を使用しています。
`git pull`が成功してからサービスを再起動してください。

```bash
cd /home/s1675dis/KakeiBOT_ex
git pull --ff-only origin main
sudo systemctl restart kakeibot.service
sudo systemctl status kakeibot.service --no-pager
sudo journalctl -u kakeibot.service -n 50 --no-pager
```
